# SIGMA

Noyau Java de simulation à événements discrets, appliqué à un terminal à conteneurs (2003, laboratoire PSI, INSA de Rouen). Le noyau a été conçu par Christophe Mames pour son mémoire d'ingénieur CNAM. Mon travail, soutenu au CESI de Rouen le 14 octobre 2003, porte sur sa version 1.1 : rétro-ingénierie, découplage, stratégies, refactoring.
